# Axie Mixer 3D asset pack (format 2)

`addons/axie_mixer_3d_assets/` is generated by `tools/unity_export/AxieGltfExporter.cs` from the Unity package `com.skymavis.axiemixer3d` 1.1.0 (plus `com.skymavis.axiemixer3d.weaponanims`). Nothing in it is authored by hand; re-export instead of editing.

The directory carries a `.gdignore`: the Godot editor never imports it, `AxieCatalog` parses the files at runtime (`GLTFDocument` for glbs, `Image.load_from_file` for textures, `JSON` for the rest). Exported games must include `addons/axie_mixer_3d_assets/*` through the export preset's non-resource filter.

## Coordinate system

Unity is left-handed Y-up; glTF/Godot are right-handed Y-up. The exporter mirrors **every** position, rotation, matrix and vertex across X once (`(x, y, z) → (−x, y, z)`, quaternion `(x, y, z, w) → (x, −y, −z, w)`, matrices `M → S·M·S`). Front stays `+Z`. A Unity yaw of θ about Y is a Godot `rotation.y = −θ`. The pack, the numeric oracle (`tests/oracle`) and the render oracle (`tests/render_oracle/index.json`) are all in this mirrored space, so the Godot side never converts anything.

Asset ids are `<guid>_<localFileId>` from Unity's `AssetDatabase`, stable across exports.

## Layout

| Path | Content |
| --- | --- |
| `catalog.json` | Bodies, parts, addons, colour table (below) |
| `bodies/<Body>.glb` | Body skeleton, skinned body mesh, and every body clip as a glTF animation |
| `weapon_anims/<Body>.glb` | Animation-only glb with the weapon package clips for that body |
| `parts/<Part>_<Rig>.glb` | One part rig prefab: its own joint chain (`*_Offsets`, `*_Scale`, `*_JNT`), skin with inverse bind matrices, skinned mesh |
| `materials/<id>.json` | Every serialized property of one Unity material |
| `textures/<id>.png` | The texture as Unity samples it (imported size, compressed texels decoded) |
| `textures.json` | Sampler settings per texture id |
| `addons/<Addon>_<Rig>__<Prefab>.json` | Mystic addon prefab dump (particle systems) |

## `catalog.json`

```json
{
  "format_version": 2,
  "source_catalog": "Packages/com.skymavis.axiemixer3d/AxieMixerAssets/AxieFactory.asset",
  "package_version": "1.1.0",
  "coordinate_system": { "source": "unity_left_handed_y_up", "pack": "gltf_right_handed_y_up_mirrored_x", "front": "+Z" },
  "default_instantiation_params": { "combine_meshes": true },
  "animation_fps": 120,
  "bodies": [
    {
      "type": "Normal",
      "glb": "bodies/Normal.glb",
      "animations": ["Dead", "Idle", "IdleCarryItem", "IdleGetHit", "Run", "RunAttack", "RunCarryItem", "Stun", "Walk", "WalkAttack", "WalkCarryItem"],
      "materials": ["<id>"],
      "attach_points": ["Root_Back_L_JNT", "Root_Back_M_JNT", "..."],
      "weapon_anims_glb": "weapon_anims/Normal.glb",
      "weapon_animations": ["AttackCombo", "AttackHead", "AttackRange", "AxeAttack", "..."]
    }
  ],
  "parts": {
    "S00_Aquatic02_L1_Back": {
      "rigs": [
        { "type": "Back_M", "glb": "parts/S00_Aquatic02_L1_Back_Back_M.glb", "prefab_name": "Model", "materials": ["<id>"] }
      ]
    }
  },
  "addons": {
    "Aquatic-Back-02-S01-LV1/Back_M": {
      "materials": [{ "name": "Model", "material": "<id>" }],
      "prefabs": ["addons/Aquatic-Back-02-S01-LV1_Back_M__Glow.json"]
    }
  },
  "colors": [
    { "index": 0, "key": "beast-00", "skin": 0, "class": "beast", "color_value": 0, "primary1": "fdfcf2", "primary2": "af8c56" }
  ]
}
```

- `bodies[]` is ordered like `AxieBodyType` (Normal, Spiky, Fuzzy, Curly, Sumo, Wetdog, Bigyak, Frosty). `animations` and `weapon_animations` are the clip names inside the glbs (canonical spelling; the weapon art bakes `Canon*`, the public constants say `Cannon*`, `AxieFactory.weapon_name_alias` bridges them). `attach_points` lists the `Root_<Rig>_JNT` bones the factory turns into `BoneAttachment3D`s.
- `parts` keys are Unity part asset names `S<skin>_<Class><variant>_L<level>_<PartType>`. A part has one rig per attach point it occupies (`Ear_L`+`Ear_R`, `Horn_L`+`Horn_R`+`Horn_T`, …). `materials` are the rig prefab's `sharedMaterials`, in surface order; the factory binds them before colorize.
- `addons` keys are `<Class>-<PartType>-<variant>-S<skin>-LV<level>/<Rig>`, exactly Unity's `AxiePartResolver.addon_name`. `materials[].name` is the child renderer to override; `prefabs` are extra glow prefabs instantiated under the attach point.
- `colors` mirrors the Unity colour table: `primary1`/`primary2` are hex sRGB, `color_value` is the gene colour nibble, `index` is the `color_variant` in `AxieDescriptor`.

## glb contents

Bodies: one scene, one `Skeleton3D`-worthy node hierarchy under the prefab root, one skinned mesh (materials referenced by id through the glTF material name), and one glTF animation per body clip. Clips are baked with Mecanim's own evaluator (a PlayableGraph on a controller-less Animator — so the clip's Loop Pose blend is in the data and the pose at `clip.length` is the held last frame, never a wrap) at `animation_fps` samples per second (120 = 4 × the 30 fps shipped art; `AxieCatalog` re-bakes the glTF tracks at that rate on load); every joint gets translation/rotation/scale channels, constant ones collapsed to two keys but never dropped, so a clip fully specifies its pose and blends exactly like Unity's PlayableGraph. Looping is a play-time choice (`AxiePlayable.play(name, "", loop)`), not a clip property — Unity clamps one-shots and holds the last frame.

Parts: the rig prefab hierarchy with the `SkinnedMeshRenderer` node's authored local TRS, its joint chain, and a skin whose joint names match `bones[]`. Godot's importer produces a `Skeleton3D` + `MeshInstance3D` per part; the factory parents the instance under the body attach point, and mesh combine unions skins by joint name.

## `materials/<id>.json`

```json
{
  "id": "<id>", "name": "Back", "shader": "Shader Graphs/S_Axie_Mixer_V5", "render_queue": 2000, "keywords": [],
  "colors":   { "_PrimaryColor": [1, 1, 1, 0], "_SecondaryColor": [1, 1, 1, 0] },
  "floats":   { "_QueueOffset": 0 }, "ints": {}, "vectors": {},
  "textures": { "_MainTex": { "texture": "<texture id>", "scale": [1, 1], "offset": [0, 0] } }
}
```

`AxieMixerMaterials.from_id` maps `shader` to a Godot shader: `Shader Graphs/S_Axie_Mixer_V5` → `s_axie_mixer_v5.gdshader`, `*Mystic*` → `mystic_final.gdshader` (+ `mystic_outline` next pass), anything else → a `StandardMaterial3D` fallback. Colour values are Unity's serialized values; the reference project is Gamma colour space, so shaders treat them as sRGB §5).

## `textures.json`

```json
{ "<id>": { "file": "textures/<id>.png", "name": "MainTex", "width": 512, "height": 512, "mipmaps": false,
            "filter": "Bilinear", "aniso": 1, "wrap_u": "Repeat", "wrap_v": "Repeat", "srgb": true,
            "alpha_is_transparency": false, "source": "Packages/.../MainTex.png" } }
```

The PNG is the imported texture read back through a GPU blit, so its texels are the BC7-decoded values Unity's shaders sample; `mipmaps: false` means Unity has mipmaps disabled for that texture and the loader must not generate any.

## `addons/*.json`

```json
{ "name": "Glow", "nodes": [ { "name": "Glow", "parent": "", "position": [..], "rotation": [..], "scale": [..],
  "particle_system": { "duration": 1, "looping": true, "prewarm": true, "start_lifetime": {MinMax}, "start_size": {MinMax},
    "start_color": {MinMaxGradient}, "simulation_space": "Local", "max_particles": 1000, "emission": {..}, "shape": {..},
    "color_over_lifetime": {..}, "size_over_lifetime": {..}, "velocity_over_lifetime": {..}, "rotation_over_lifetime": {..},
    "noise": {..}, "texture_sheet_animation": {..}, "renderer": { "render_mode": "Billboard", "material": "<id>", ... } } } ] }
```

`MinMax` is `{ "mode": "Constant|Curve|TwoConstants|TwoCurves", "constant", "constant_min", "constant_max", "multiplier", "curve": [17 samples] }`; gradients carry Unity colour/alpha keys. `AxieMysticGlow` builds `GPUParticles3D` from this. Particles are excluded from the render oracle on both sides.

## Verification

`tests/oracle_compare.gd` (numeric, 1615 checks) and `tests/render_compare.gd` (pixels) are the acceptance tests for the pack; `tests/run_tests.gd` includes a catalog-integrity suite (every referenced glb/material/texture exists).
